Workflow Steps:

1. User requests to build a weather module in ChatModule
2. ExecutorChatModule creates the initial file with placeholder API key
3. ChatModule sends "Test it" command
4. ExecutorChatModule reports "Error: API key missing"
5. ChatModule sends a fix with a real API key
6. ExecutorChatModule reports "Success"
7. ChatModule reports "Success: Weather module built successfully!"
