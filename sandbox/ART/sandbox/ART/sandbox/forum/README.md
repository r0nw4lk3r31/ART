# Forum Website Setup

## Backend Setup
1. Navigate to the `forum` directory.
2. Run `npm install` to install dependencies.
3. Start the server with `npm start`.

## Frontend Setup
1. Navigate to the `forum/client` directory.
2. Run `npm install` to install dependencies.
3. Start the development server with `npm start`.

## Notes
- Use React with Tailwind CSS for the frontend.
- Use Node.js with Express for the backend.
- Implement user profiles, password login, post creation, and discussion threads.
- Use file-based storage (JSON) for data persistence.
